Building a modern, production-ready full-stack web application called "CapsuleX".

CapsuleX is NOT another Instagram clone.

It is a social network where content gains value over time instead of disappearing.

The core philosophy is:

"Memories are meant to be unlocked, not endlessly scrolled."

The design should feel premium, emotional, futuristic, and minimal, inspired by Apple, Notion, and Spotify.

MAIN FEATURES
===================================

## 1. Time Capsules ⭐

Users create posts called Capsules.

Each capsule can contain

- Images
- Videos
- Text
- Voice Notes
- PDFs

Each capsule has an unlock condition.

Examples

✓ Open after 1 day

✓ Open after 1 month

✓ Open after 5 years

✓ Open on birthday

✓ Open on graduation

✓ Open on anniversary

✓ Open on custom date

Locked capsules cannot be viewed before unlock.

Show beautiful countdown timers.

===================================

## 2. Conditional Unlocks ⭐

Capsules may unlock when conditions become true.

Examples

Lose 15 kg

GOAL
===================================

This application should NOT feel like Instagram.

It should feel like a premium emotional platform where people preserve memories, communicate with their future selves, and experience time in a completely new way.

Users should leave feeling nostalgic, hopeful, and emotionally connected to their own journey.

Code should be modular, scalable, production-ready, and follow clean architecture with reusable components, proper folder structure, REST APIs, authentication, protected routes, responsive design, error handling, loading states, optimistic UI updates, and best coding practices.
